What Wigwag is

Project-management semantics, stripped to the essentials.

Not a hosted tool, not a protocol you have to run. Wigwag is a small set of rules for tracking work — encoded into a single portable artefact that behaves the same wherever it ends up.

Portable by default

The whole project lives in one artefact. Copy it, email it, drop it on a USB stick — it needs nothing else to work.

Zero provisioning

No server to stand up, no workspace to configure, no account for every collaborator. If you can open a file, you can use Wigwag.

Conflict-native

Two people edit the same artefact offline, then reconnect — Wigwag merges the history itself instead of asking you to resolve it.

Who it's for

For project managers working across organisations.

Consultants, freelancers, contractors — anyone coordinating a project with people outside their own company, where no single organisation's tools or accounts cover everyone involved.

Wigwag assumes the person on the other side is in the same position. Neither of you lives in the other's tools — you just pass the artefact back and forth, each edit it on your own time, and let it merge itself.

How it works

One artefact, no coordination step.

Each collaborator holds a full copy. There's no central server to be the source of truth — the merge semantics are.
